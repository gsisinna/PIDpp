## 0.1.0 - Unreleased

### Added

- Initial C++20 PIDPP SDK structure.
- PID controller with anti-windup, derivative modes, optional derivative filtering, feedforward, and state inspection.
- Core validation, result, version, filter, simulation, autotune, and metrics modules.
- CMake package export, pkg-config generation, examples, tests, and CI scaffolding.
- Optional PIDPP Control Lab GUI for interactive simulation and visualization.
