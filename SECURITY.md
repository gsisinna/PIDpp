# Security Policy

PID++ Control Engine is pre-1.0 software.

Please report security-sensitive issues privately through GitHub Security Advisories ("Report a vulnerability" on the repository Security tab) rather than opening a public issue. Include a minimal reproduction, affected version or commit, and expected impact.

The project does not currently process untrusted network input. Most security-relevant concerns are expected to involve build system supply chain issues, undefined behavior, or unsafe integration into robotics systems.
